# BEYOND THE SPOTLIGHT · 스포트라이트 너머의 마이클 잭슨

全球研讨会课程的 15 分钟韩语演讲舞台。整个网页是一座只有一盏「跟光」的剧场：光照到的是传奇，光照不到的是这个人。

- 13 个场景、59 个节拍，翻页器「下一页」推进一切效果，「上一页」精确倒回
- 跟光引擎：光外的字真的在暗处；光束穿过灰尘，每个年代换一种胶片（底色、颗粒、粒子、光的行为）
- 画面文字中韩双语，`L` 在 韩文 / 中文 / 双语 之间切换
- 演讲者视图、下一拍预览、节奏偏差、课前预检、排练记录，全部在同一个 `index.html` 里
- 迈克尔的插画是一具「骨骼人偶」：同一个人按年代换装（杰克逊五兄弟的爆炸头、Off the Wall 的燕尾服、Thriller 红夹克、Smooth Criminal 白西装、超级碗军装、This Is It 排练线稿），会走、会太空步、会 45° 前倾、会鞠躬
- 鼠标可以探索（全部可选，不影响翻页）：移动是手电筒和视差，卡片、唱片、票根、胶片会随指针倾斜，人物可以点、可以拖
- 六张迈克尔本人的照片（1969、1983、1984、1988、1992），来自 Wikimedia Commons 的公有领域 / CC 图片，署名印在相纸上，见 [media/README.md](media/README.md)
- 三档画质（高 / 标准 / 省电），按设备自动选择；翻页后如果连续卡顿会自动降一级，并记住这台电脑的选择。详见下面「画质与流畅度」

## 打开方式

| 方式 | 做法 |
| --- | --- |
| 本机（推荐） | 双击 `Start (Mac).command` 或 `Start (Windows).bat`：在本机开一个 http://localhost 服务并自动打开浏览器，演讲时别关那个窗口。Mac 第一次要右键 → 打开；Windows 没装 Python 时自动改用 PowerShell。视频文件支持拖动进度 |
| GitHub Pages | 仓库 Settings → Pages → Deploy from a branch，选这个分支和 `/ (root)`，保存后打开 Pages 给出的 https 地址（手机上看用这个） |
| 不要 | 直接双击 `index.html`：`file://` 下 YouTube 嵌入会报错（本地音乐不受影响） |
| claude.ai 预览链接 | 只适合看排版：预览环境不允许嵌入 YouTube、也不能加载外部图片，视频页显示说明卡，照片只有放进 `media/photos/` 并一起发布时才出现 |

## 演讲当天

1. 投影窗口打开页面，点一下画面，按 `F` 全屏。
2. 按 `P` 打开演讲者视图，把它拖到笔记本屏幕。翻页器在两个窗口里都能用。
3. 按 `S` → 课前预检 → 全部检测，一屏全绿再开始；「全部预热」会把视频静音预加载一遍。
4. 按 `→` 开始，计时从第一拍开始。浏览器意外刷新会回到刚才的节拍，计时不丢。

## 鼠标互动

| 在哪里 | 怎么玩 |
| --- | --- |
| 任何一页 | 移动鼠标：一束小手电跟着指针，暗处的字和人会被照亮；画面分层轻微视差。停 3 秒自动收起 |
| 冷开场 ②–⑤ | 点一下人物：重现摩城 25 的扶帽、踢腿、转身、踮脚 |
| 冷开场 ④⑤ | 左右拖动人物：倒放 / 快进太空步，每一步留下残影 |
| 加里 ② | 点小迈克尔：五兄弟一起排练 |
| Thriller ③ | 点电视旋钮：在插画（会亮的地砖）和真实 MV 之间换台 |
| Thriller ⑥续 | 指针移到胶片格上：格子里的僵尸舞会动 |
| Bad ⑥ | 拖动白西装人物：改变倾斜角度，超过 30° 数字变色 |

## 画质与流畅度

| 画质 | 什么时候用 | 效果 |
| --- | --- | --- |
| 高 | 电脑上的 Chrome / Edge 默认 | 全部效果：胶片颗粒抖动、漏光、灰尘与年代粒子、人物发光与亮片闪烁 |
| 标准 | Mac 上的 Safari 默认；或「高」卡顿时自动降到这里 | 颗粒静止、漏光不动、粒子减半、灯光层不做混合 |
| 省电 | 手机、平板、演讲者视图里的预览；或「标准」仍卡时 | 关掉滤镜、粒子和整屏叠加层，只保留跟光本身；不嵌入视频（显示卡片和链接） |

- 设置 → 演讲 → 画质：默认「自动」，也可以手动固定。设置面板里会显示当前画质、为什么是它，以及最近一次翻页的帧率。
- 自动降级的判断：翻页后 2.6 秒内的中位帧间隔超过 26 ms，或者最慢的一成帧超过 60 ms，并且连续两次都这样，才会降一级。降级提示只发到演讲者视图，不会出现在投影上。
- 想在排练时强制某一档：网址后加 `?q=high`、`?q=standard` 或 `?q=low`。
- Safari 和所有 iOS 浏览器上，舞台用 CSS `zoom` 缩放，不用 `transform`：WebKit 给每个合成图层分配显存时只看设备像素比、不看外层缩放，用 transform 时 iPhone 上一个铺满舞台的图层就要约 75 MB。`?zoom=0` / `?zoom=1` 可以强制切换。
- 画面静止时，灯光画布不再重画；只有灰尘和年代粒子在一张低分辨率画布上以每秒 24–30 帧更新。

## 在哪里打开才有视频和音乐

- **能内嵌播放全部视频、MV、背景音乐的地方**：GitHub Pages（仓库 Settings → Pages → Source 选「Deploy from a branch」，分支选 `claude/webpage-design-30s4a0`、目录 `/ (root)`，保存后地址是 `https://linbingbo4-sketch.github.io/MJ-/`），或者在本机文件夹里运行 `python3 -m http.server` 后打开 `http://localhost:8000`。
- **claude.ai 预览页**：平台的安全策略禁止在线视频和外部图片。在这里点 MV 开关或按 V，播放窗口照样在页面里展开，但会显示「这里无法播放」；要真正播放，用本机或 GitHub Pages 打开。
- 手机上为了不崩溃，YouTube 播放器在第一次点击之后才加载，只用一个；iOS 不允许网页调节 YouTube 音量，背景音乐在 iPhone 上没有淡入淡出。

## 视频开关、MV 与字幕

- **全手动（默认）**：每按一次 → 先走这一页字幕的下一句，句子走完才翻页；← 同理往回。右上角的 **∞**（或 <kbd>A</kbd>）打开自动演出：字幕按排练语速走，页面自动翻页，∞ 上会有一道光沿着弧线流动；再点一次关闭。
- **视频进度条**：MV、预告片和 Smooth Criminal 播放时，下方有进度条——拖动或点击跳到任意位置，±10 秒，播放 / 暂停；整屏预告片时鼠标不动 2.6 秒后自动隐藏。
- **Billie Jean**：显像管电视和可选的 ⑤ 都改放 1983 年摩城 25 周年的现场演出（第一次太空步），不再放 MV；电视里的小人也改成太空步。翻到这一页时，一个太空步的身影从右向左滑过舞台，新的画面在他身后展开。
- **3D**：换场时镜头向前推进新的一场；章节卡像挂牌一样从上方翻下来，罗马数字转过来；唱片封套落下时转向观众；标题页的照片随鼠标轻微倾斜。省电档和「减少动态」时关闭。
- **标题页**：以一张 1988 年 Bad 巡演的迈克尔照片（Zoran Veselinović, CC BY-SA 2.0）为画面中心，标题围绕它排布，光扫过后落在他身上；三幕路线图出现时，照片退到后面变暗。
- **音效**：Off the Wall 一场里「假声 / 呼吸声 / 打嗝般的短音」出现时各有对应的合成人声音效（点标签可重播）。
- **第六章「阴影」**：整体调暗；两个人物改成只有轮廓线的形象，歌名是空心描边字，上面有一道缓慢的反光。
- **V 键**：随时播放 / 关闭这一页的视频（预告片、Smooth Criminal 提示点等）；这一页没有排好的视频时，播放画面上第一个作品的 MV。**Esc** 关闭 MV。
- **MV 开关**：MV 一律在页面里的窗口播放：先用本地文件（`media/mv/作品.mp4`，见 [media/README.md](media/README.md)），没有才用嵌入的官方播放器，不会跳到任何网站。舞台上出现的每部作品旁边都有一个小开关（唱片封套下方的小标签、榜单上的小胶囊，颜色取自作品本身），一共 23 部。点一下，MV 从开关的位置展开播放，音乐自动让位；再点一次、按 V / Esc、或点画面外面就收回。每部作品备有 1–3 个官方视频 ID，前一个被禁止嵌入时自动换下一个。
- **「这个 MV 需要播放吗？」**：这一页有可以播放的 MV 时，右上角（正在播放卡片下方）会出现提示——一部作品时问「이 MV를 재생할까요? / 这个 MV 需要播放吗？」，几部作品时问「어떤 곡을 재생할까요? / 该播放哪首呢？」并列出曲目，点曲名就播放。几秒后它收成一个小按钮，点一下（或鼠标移上去）重新展开；× 关掉这一页的提示。
- **中韩字幕（U 键开关，默认打开）**：讲稿逐句显示在画面底部，韩文在上、中文在下，按排练语速切换；视频的提示点字幕和可选的预告片字幕轨也一律是韩文在上、中文在下。
- **右上角的「正在播放」卡片**：每一场都常驻显示这一时期的代表作——歌名、年份、风格（韩文 / 中文），杰克逊五兄弟时期另有「THE JACKSON 5 · 잭슨 5 · 杰克逊五人组」标签；音乐在响时唱片转动、显示 NOW PLAYING。
- **音效**：开场场记板合上时「咔」的一声；人物剪影走路时有脚步声（雨中那一场是湿的脚步声），太空步每一步有鞋底滑过地板的声音。
- **背景音乐从标题页开始**：预告片之后的标题页响起《Wanna Be Startin' Somethin'》（预告片的最后一首），之后杰克逊五兄弟时期是 *I Want You Back*，个人时期依次是各时期代表作。

## 声音与预告片

- **年代音乐**：每个年代有一首代表作（I 加里 *I Want You Back* · II *Don't Stop 'Til You Get Enough* · III *Billie Jean* · IV *Bad* · V *Black or White* · VI *Stranger in Moscow* · 间奏 *Earth Song* · VII *Human Nature* · VIII *Remember the Time* · 终幕 *Man in the Mirror*）。每首先找 `media/music/` 里的本地文件，没有就依次试 YouTube 上的官方音源（一首备一到两个视频 ID，被禁止嵌入时自动换下一个）。
- **转场不留空档**：下一年代的歌在当前年代里就提前载好；转场时旧歌一直响到新歌真正出声，然后按等功率曲线交叉——年代溶解约 2.6 秒，场灯渐亮约 3.4 秒；幕间黑场时旧歌在 0.9 秒内收掉，新歌随灯光升起。
- **效果音**（全部合成，不需要文件，设置 → 音量 里可调或关闭；「减少动态」时自动关闭）：年代溶解的气流声（最响的一刻正好落在两首歌交叉处）、幕间黑场的电闸声与追光灯点亮声、遗产一场的场灯渐亮、章节卡的一声低音、预告片的放映机倒数与胶片走完。
- **预告片**：默认用环球影业的官方二版预告——韩文画面播环球影业韩国的〈마이클〉2차 예고편（`D5Wbzgi6Ivs`），中文画面播环球影业香港的《米高積遜》次回官方預告（`2eWMoPkRx0U`），同一版剪辑、各自带官方字幕；双语画面用韩文版。播放顺序：银幕转正 → 银幕上 3·2·1 → 画面从银幕放大到整个舞台 → 放完定格、缩回银幕 → 放映机停下。没有出点时完整播放，并在片尾前 0.35 秒停住，不会露出 YouTube 的推荐视频。
- **预告片字幕（可选）**：设置 → 视频与音乐 → 预告片字幕，每行「时间 | 韩文 | 中文」，双语画面里中韩两行一起出现；时间可以先空着，预览时每句开口按一次「打点」。
- **时间预算**：完整预告片约 2 分 20 秒，第 1 场的预算跟着片长走（有出点按出点算，播过一次后按实测时长算）。完整播放时全场计划约 16 分钟，超出 15 分钟的上限；需要压回 15 分钟时，给预告片填一个出点（例如 45 秒，全场约 14:27）。

## 还需要你补上的

- **Smooth Criminal 提示点**：默认链接是官方视频 `h_D3VFfhvs4`。排练时播放它，按 `C` 依次记录 ①起点 → ①终点 → ②起点 → ②终点。
- **在投影电脑上跑一次预检**：设置 → 课前预检 →「全部检测」。官方视频偶尔会被所有者改为禁止嵌入，预检会告诉你哪一个需要换链接。
- **标题页署名**：设置 → 演讲 里改姓名、课程和所属（中韩各一份）。

所有设置、提示点和排练记录都存在这台电脑的浏览器里；换电脑时在 设置 → 排练记录 里导出 / 导入 JSON。

## 修改与发布（给以后的自己）

- `index.html` 由 `src/*.part` 拼出来：改 `src/` 里的文件，再运行 `python3 build.py`。
- **电脑和手机必须一致**：画质档只能让效果变便宜，不能把效果去掉。每次推送前运行
  `node tests/parity.js http://localhost:8000/index.html`（先在仓库目录 `python3 -m http.server 8000`），
  它逐拍对比电脑和 iPhone 上看到的东西，手机少了任何一样都会报错。规则写在 `CLAUDE.md`。
